DAPUR NUSANTARA — TEMA CERIA DAN BERWARNA

Susunan file:
  index.html         Halaman beranda
  profil.html        Profil usaha, visi, misi, dan nilai
  galeri.html        Galeri menu
  data.html          Tabel menu dan harga
  style.css          Seluruh desain website
  assets/images/     Ilustrasi SVG yang dipakai halaman

Cara menjalankan:
  1. Ekstrak ZIP.
  2. Jangan pindahkan file HTML, style.css, atau folder assets dari tempatnya.
  3. Buka index.html menggunakan browser.
  4. Gunakan navigasi untuk berpindah halaman.

Catatan:
  - Dibuat dengan HTML5 dan CSS3, tanpa framework dan tanpa JavaScript.
  - Semua aset disimpan lokal sehingga bisa berjalan offline.
  - Tampilan responsif (desktop, tablet, ponsel).
  - Menu dan harga merupakan data contoh untuk tugas kuliah.
